# ⚡ Locket - Quick Start para Demonstração

## 🚀 Iniciar em 3 Passos

### 1️⃣ Abrir o Sistema
```
http://localhost/locket/login.html
```

### 2️⃣ Login Instantâneo (Admin)
Na página de login, há um botão amarelo:
```
⚡ Usar Credenciais Admin
```
Clique para pré-preencher automaticamente as credenciais de administrador.

**Ou faça login manual:**
- Email: `professor@universidade-testes.edu.br`
- Senha: `secret`

### 3️⃣ Pronto! 🎉
Você está no Dashboard administrativo com acesso a:
- 📊 Métricas e estatísticas
- 👥 Gerenciamento de usuários
- 📦 Controle de ativos
- 📋 Auditoria do sistema
- 📈 Relatórios avançados

## 📸 O Que Mostrar para o Cliente

### Interface Administrativa
- **Dashboard** - Visão geral com KPIs
- **Usuários** - Gestão de contas (criar, editar, ativar)
- **Ativos** - Inventário de equipamentos
- **Auditoria** - Log de todas as ações
- **Relatórios** - Análises e exportação de dados

### Funcionalidades Principais
✅ Autenticação segura com JWT  
✅ Gestão de usuários por perfil  
✅ Controle de ativos e empréstimos  
✅ Sistema de auditoria completo  
✅ Relatórios avançados  
✅ Interface responsiva (mobile-friendly)  
✅ Validações em tempo real
